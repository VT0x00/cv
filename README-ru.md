## Проекты

### DeKVS — распределённое key-value хранилище
**Стек:** Go, HashiCorp Raft, gRPC, Protobuf, PostgreSQL, Prometheus, Grafana, Docker.
**GitHub:** github.com/VT0x00/dekvs

Отказоустойчивое распределённое хранилище с консенсусом Raft и gRPC-API.

**Что сделано:**
- Реализовал кластер из 6 узлов с автоматическим выбором лидера и репликацией лога.
- Спроектировал gRPC-сервис с операциями `Put`, `Get`, `Delete`, а также batch-операциями.
- Настроил автоматическое подключение узлов к кластеру при старте.
- Добавил health/status-эндпоинты и сбор метрик через Prometheus.
- Подготовил готовые Grafana-дашборды для визуализации состояния кластера.
- Написал `docker-compose.yml` для запуска полного кластера одной командой.

**Результат:** проект разворачивается через `docker-compose up -d --build`, документация описывает запуск локально и в контейнерах.

### VyborOk — платформа для опросов и голосований
**Стек:** Go 1.21+, `micro v3` (`micro-server-http/v3`), Protobuf, PostgreSQL 16, Redis (план), NATS (план), Docker Compose.
**GitHub:** github.com/VT0x00/VyborOk

Backend платформы для проведения опросов. Ранний MVP: аутентификация готова, опросы/голоса/статистика в разработке.

**Что сделано:**
- Реализовал регистрацию, логин, refresh-токены, JWT-авторизацию и получение профиля.
- Спроектировал API на Protobuf с аннотациями `micro.api.http`.
- Настроил миграции и работу с PostgreSQL через `make migrate-up`.
- Реализовал публичные и приватные профили с полем `is_private` и companion-полями `*_set` для proto3.
- Подготовил инфраструктуру через Docker Compose (Postgres, Redis, NATS).
- Описал API в README с примерами curl-запросов для каждого эндпоинта.

**Результат:** сервер поднимается командой `make run`, health-check доступен по `/health`, все ключевые эндпоинты задокументированы.
